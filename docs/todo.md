## Открытое из аудита

- Проход Narrator по панели и окну; автотест «у каждого виджета есть имя для UIA».
- Клавиатурный режим панели проверен только самопрогоном — проверить руками.
- Ползунок Windows «Размер текста» (TextScaleFactor): панель фиксированной толщины.
- Одна ручка «Размер панели» вместо «Толщины» и «Размера значков и цифр».
- Раскладка по набору мониторов (по EDID), а не только по их числу.
- «Нет данных» на панели (прочерк у наушников): контраст не ниже 3:1 и подсказка.
- Подпись exe (Authenticode), чтобы SmartScreen не предупреждал.
